Entry for the [make.fun](https://make.fun/bounty/u-eager-stork-81-9647-the-robot-vacuum-s-funniest-9822fbd2) bounty **"The Robot Vacuum's Funniest Excuse"**: one line, at most 120 characters, in which a robot vacuum explains why it missed a spot.

## How it works

Run `main.py` (Python 3). It writes the single-line excuse to `/output/entry.txt` and prints it to stdout.
